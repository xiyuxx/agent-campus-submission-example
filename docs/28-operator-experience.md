# 局部失效、本地时间和轻量交接契约

用户授权先完成体验与评审改进，保留第27号任务语义及全部硬验收，不接真实发布，不增加前端、团队素材表或完整交接系统。

## 依赖与确认

全局目录版本继续用于运行中观察的并发校验；已保存方案按自身有效素材/补充来源、当前规则、选定账号时段和必要默认候选追踪。补其他素材、其他账号排期或增加无关时段不得让当前方案失效。当前全局规则适用于全部素材，因此规则变更仍需相关审核。素材被移除、有效事实/规则改变、当前时段冲突、目标到期或已选默认候选被撤销时失效。

更新事务只使实际受影响的草稿stale，返回其ID和原因；预览采用相同依赖检查。未受影响方案保留草稿ID、修订和确认；历史证据不改写其原目录版本。复查/复用允许历史目录版本的草稿，但保存仍要求本轮最新观察并消费真实回执。更换实际方案或审核依据继续重新判断确认，不能代签。

## 运营输入与显示

按用户要求，work交互直接使用电脑本地时区，无需输入IANA名称。普通日期时间使用“2026-11-03 22:00”，程序按操作系统在该日期的本地偏移转换；不存在或歧义的夏令时本地时间拒绝并要求明确带偏移的时间。内部保留明确UTC时刻。输入timezone=local代表本机本地展示，已经保存的绝对时刻不随本机时区变更改写；旧IANA/ISO JSON接口保留。

主界面显示本地日期时间及UTC偏移、中文审核/确认/保存状态；改期提示也转换为本地时间。是否必须在该时间、是否允许查询其他候选分别表达；候选始终不代表批准改期。按缺项逐字段补资料，版权和素材类型用中文选项，文件/正文等用普通输入；无缺项时可显式选择白名单字段更新。身份、审核规则、确认和保存权限不开放给模型或资料文本。

## 交接和评审

按扩展名支持JSON与CSV；CSV包含素材/标题/账号/平台、本地时间与偏移、审核/风险、确认、草稿版本和真实保存状态。导出前重新核验，只包含当前可交接方案。增加按内容生成的稳定版本标识、导出时间和“静态快照，执行前核对”的提示；同内容JSON/CSV版本相同，改期/取消/事实变化后版本改变。不把导出当成已经交付或实际发布，不自动修改旧附件，不建设批次回执或通知。

README首屏放快速运行、六项验收、两条live及限制，历史文档索引下移。合成JSON为初始化资料，日常修改以数据库为当前状态；完整重导入仍是显式快照更新。补一次全新安装后的完整离线复验；失败如实保存，不跳过或把分批通过冒充一次整套通过。
