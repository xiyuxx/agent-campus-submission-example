# Agent 决策信息与恢复契约 v1

2026-10-31，用户授权实施。本文补充第 13、19、23 号规范；保留模型消费真实观察后选择动作、单份草稿、改期待确认、本地身份绑定及保存事务语义。以下先定义设计，实际结果在阶段记录中另记。

## 审核信息

读取观察提供缺项、是否已补查以及补充来源是否存在；检查观察提供 blocking_missing_fields（实际命中 needs_info 且值未知的字段）、other_missing_fields（其余未知字段）、supplement_available、supplemented。其他缺项不代表全部可选：其风险仍以 matches 为准。blocked 优先级不变；不改变整体补充资料冲突校验，不伪造授权。

## 改期偏好与兼容

publish_requirement 新增 reschedule_preference=nearest/prefer_before/prefer_after，默认 nearest。偏好不改变查询范围：仍找两侧各一个最近空闲节点；原时间可用时必须优先原时间。偏好是推荐依据，不能授权改期。nearest 等距时模型可推荐任一，但必须如实说明等距；Mock 保留等距优先后一个的工程策略。只保存一份推荐草稿，暂不增加保存前多方案交互。

默认 nearest 在 canonical 中省略，保持原 schema_version=1.0 请求和旧数据库摘要兼容；非默认偏好纳入 canonical、幂等比较及草稿语义。同 request_id 改变非默认偏好必须拒绝，不自动覆盖。模型看到显式默认值，不需要内部 ID。

## 动态工具边界

模型请求根据可信上下文计算工具集合，执行入口同时核对该轮实际提供集合与执行时状态。低层 Repository/直接工具工程测试不模拟模型权限；run_item 始终传递工具集合。Schema 隐藏不能代替数据库校验。

read_material 用于读取和刷新；有素材时可 check_rules；只有当前已送达、允许继续的审核且要求完整时可 query_slots；只有最新已送达的可用查询、有效审核、非拒绝方案且无待恢复冲突时可 save_draft。明确不可恢复技术错误或 unknown 时不提供业务工具。结束仍由真实状态验证，必要的模型回执消费不省略。

## 保存冲突恢复

只有实际 save_draft 的 SLOT_CONFLICT 进入排期恢复；成功查询中的 SLOT_CONFLICT 只是原时间占用的事实。返回 recovery_action=query_slots，并标记旧查询不再具备保存资格，保留历史证据。模型必须重新查询、消费新候选，再推荐保存；程序不自动换时间。一次素材最多两次因保存冲突发起的重新查询，总模型/工具/时间预算仍有效；再次冲突且恢复次数耗尽时 incomplete/RECOVERY_LIMIT。重复旧保存、提前结束不能绕过刷新。

unknown 不自动重试写入；版本冲突不直接改用最新修订覆盖。其他技术错误继续遵守有限重试与诚实失败。

## 审核扩展边界

提取本地规则审核的小接口和默认实现，检查时从短读事务取得快照与规则，再在事务外执行审核；返回必须匹配输入素材摘要、目录和规则集。保存事务继续独立执行本地规则复核。

本轮只运行本地元数据审核。远程视频审核尚未选择服务，不实现远程任务、轮询或报告持久化，也不能直接用远程结果替换本地保存复核。后续接入必须增加绑定素材版本/策略/有效期的报告存储，区分 running、调用失败和业务结论；远程调用不得置于 SQLite 写事务中，供应商任务身份留本地。

## 验证与阶段

1. 本契约文档先本地提交。
2. 审核观察、动态工具与本地审核接口：检查必要/其他缺项、错误身份、阶段工具、供应商报文和旧回归。
3. 改期偏好及恢复：检查默认摘要兼容、非默认请求冲突、原时间优先、等距、双向偏好、查询后抢槽、旧候选拒绝、恢复耗尽和 unknown。
4. 生成实际合成运行及显式 live 正常/补查或冲突恢复路径，保存配置、观察关联、数据库结果与限制；同步五份交付文档。live 失败不能写成通过，不归档原始密钥或内部思维。
