# 方案与技术取舍

Python 3.13 + CLI + 原生单 Agent + DeepSeek Tool Calls + HTTPX + Pydantic + SQLite。没有增加框架、多 Agent、Web 或真实发布。依赖精确版本见 requirements.lock。当前业务契约见 [第27号修订](27-task-workflow.md)，历史参考中冲突条款由该文覆盖。

## 用户操作与模型决策

调用关系为 work CLI → 小型任务服务 → 现有 run_request/确认服务 → 模型工具循环及 Repository。任务层处理清单、用户修改、补资料、取消、恢复和交接；模型继续消费真实工具结果，再选择业务动作。用户确认、身份、版本和数据库回执由程序控制，不能让模型代签。

四类工具 read_material、check_rules、query_slots、save_draft 继续存在。资料不足时模型可以选 supplement，之后重新审核；风险可选待确认或明确阻断；查询返回原时间及必要的两侧节点，模型推荐一个；保存抢槽或候选到期返回 recovery_action=query_slots，模型消费错误后重新选择，受原范围及预算约束。

工具 Schema 随可信状态收窄，执行边界再次检查。最低完整性为公开系统规则，扩展规则来自目录。模型消息只投影必要业务事实，身份、修订、观察引用本地绑定。成功保存必须把回执回传模型，再允许结束；Mock 的确定性分支只验证工程流程。

## 任务、请求与草稿

publication_tasks 以素材/平台/账号唯一，生命周期不随版本或请求 ID 改变。requests 保存不可变要求；task_requests 关联要求版本、旧草稿并发前置条件、运行结果和证据目录。drafts/draft_history/confirmations 继续承担实际保存、修订与批准事实。

相同要求重跑复用当前请求和未变方案；用户修改要求才生成新请求。新方案保存时在同一短写事务将旧方案 stale、写新草稿与历史、更新任务指针。任何失败整体回滚，旧有效草稿仍存在；工作清单显示修改未完成，不导出旧方案。旧请求不能覆盖当前要求，new_publication 不再绕过唯一性。

SQLite v2 增加任务表、关联表、事件和 active 素材唯一索引。迁移预检多份同素材/账号 active 草稿，有歧义整体拒绝；不静默合并。保留历史和外键，延迟指针外键在提交时验证。无网络或模型调用发生在写事务中。

## 时间、确认和真实性

业务时钟与真实审计时钟分离；--as-of 明确记录回放，预算使用 monotonic。首次计划不能使用过期要求；已有已确认未来方案仍有效时允许复用，不能顺带授权其他改期。新用户要求与模型建议分开，候选不是批准。

批准绑定草稿修订；改变方案重新计算待确认项。读取、重放确认、工作清单和导出重新检查时间、目录、素材、规则和占用。历史确认回执可仍是 confirmed，而当前方案已 stale，两者分别返回。

保存失败保留有依据的 proposed_plan，并明确 not_saved/unknown/requires_recheck；它不能充当已保存草稿或直接确认。回执丢失使用内部写入凭据核验，结果未知停止，后续继续先读取数据库再决定是否保存。任务结果记账失败也返回失败，并追加与公开结果一致的 final Trace。

取消为明确用户操作，使任务 cancelled、草稿 stale 并释放本地容量，保留历史。恢复必须明确选择并重新检查。可交接表示当前要求对应的本地草稿有效且确认完成；导出只从数据库新鲜状态生成，不声称平台预约或发布。

## 执行与资料更新

每项模型/工具各16次、180秒；每次最多三项、整批540秒；传输、协议和恢复重试均有界并计入预算。work 批量沿用整批截止时间，单项失败保留其他项结果。

补资料由用户明确输入 BusinessFacts 白名单，校验类型并递增素材版本，经完整目录更新服务提交；目录版本作为并发前置条件。同名旧补充字段由明确用户更新取代，其他来源保留。沿用保守目录失效策略，可能使无关任务也需复查。

Trace 自动记录步骤、工具参数、返回摘要、简短依据和送达观察，run.json 记录模式、源码摘要、实际模型标识、usage、预算和退出码，不存内部思维过程。评估分别报告离线与 live，小样本不外推稳定成功率。

## 取舍与限制

CLI 兼顾运营交互和工程复现；HTTPX 隔离传输、Pydantic 校验边界、SQLite 提供事务和幂等。原生循环足以表达当前四工具，不为框架加复杂度。任务层增加必要生命周期能力，沿用现有审核/查询/保存核心。

审核仍只覆盖合成元数据；无视频理解、企业鉴权、真实发布、全局最优、长期高并发或断电恢复保证。取消不撤销外部发布；交接之后的变更需协调发布人员。模型和离线时钟限制详见当前评估。
