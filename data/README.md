# 数据约定

此目录已有合成素材、补充资料、规则、排期及示例请求，供 CLI 导入与离线复现。

- 固定样本 ID 和生成种子（涉及随机生成时），记录来源与用途。
- 正常、资料不足和工具失败场景应可独立复现。
- 区分业务事实、业务规则和测试注入的故障。
- 不使用真实手机号、凭据或私人业务资料。
- 需要检索时记录资料 ID 和版本，便于核查输出依据。

普通示例请求省略 candidate_times，使用账号的 allowed_slots 预设节点，冲突后在原时间两侧各找一个最近空闲节点，允许跨日。request_id、material_id 是本地请求/素材身份，不进入模型业务消息；模型工具仅处理当前素材。演示请求改用 REQ-DEMO-NEAREST-V2，因为删除旧显式候选改变了原始输入，不能复用旧演示请求标识。已有明确候选与 [] 仍保留范围限制语义。
